Commit and push the working tree according to `docs/git-strategy.md`. Read that
file first — it is the specification, this command is its execution.

Arguments given: $ARGUMENTS

Treat the arguments as a hint about intent, never as the commit message. The
message comes from the diff.

**This command cannot merge.** `gh pr merge` is absent from `allowed-tools`
above, deliberately: opening a PR and merging it are separate decisions, and
merging is `/git-merge`.

All output is English.

## 1. Sync

```bash
git fetch origin
git status --porcelain=v2 --branch
```

If the current branch is behind, `git pull --rebase --autostash origin <branch>`.
This cannot conflict — CI only writes `pdf/*.pdf` and the marker blocks in
`README.md`, neither of which is hand-edited.

**Warn if the tree had staged changes before the autostash**, because it
restores them unstaged. Say so plainly; the content survives, the staging does
not.

Never rebase a branch that has an open PR.

## 2. Survey

```bash
git status --porcelain
git diff
git diff --cached
```

Read the whole diff, not the stat. You are about to write a commit message
claiming what it does.

## 3. Refuse

Stop and report, without committing, when:

- **`pdf/**` is dirty.** Those are CI's; a local `latexmk` run leaked into the
  repo. Tell the user to `git checkout -- pdf/`.
- **The diff falls inside a `<!-- BEGIN … -->` / `<!-- END … -->` block in
  `README.md`.** Those are generated by `update-readme.yml`; the edit will be
  overwritten on the next push. Prose *outside* the blocks is fine.
- **The tree is clean.** Say so and stop. Do not invent an empty commit.

## 4. Classify

Sort every changed path into two buckets, per the table in
`docs/git-strategy.md`:

- **SHARED** — `scripts/**`, `.github/**`, `.latexmkrc`, `tex/preamble.tex`,
  `tex/colophon.tex`. Requires a branch and a PR.
- **CONTENT** — everything else: `tex/<topic>/**`, `README.md` prose,
  `CLAUDE.md`, `docs/**`, `.claude/**`. Goes straight to `main`.

`tex/preamble.tex` and `tex/colophon.tex` are SHARED despite living under
`tex/`; `tex/<topic>/**` is CONTENT however many topics it spans.

### Changes the user did not ask about

The working tree may hold work in progress that has nothing to do with this
invocation — another session's, or something started and abandoned. **Name
those files explicitly in the plan and ask before including them.** Do not
quietly fold them into a commit because they happened to be dirty.

The signal is a file whose change is unrelated to `$ARGUMENTS` and to the rest
of the diff. When in doubt, ask; a commit is easy to make and impossible to
unmake once pushed.

## 5. Gate

Run the checks the change earns, **before** any commit exists, so a failure
leaves nothing to undo. Abort on the first failure and report it verbatim.

| Changed | Gate |
| --- | --- |
| `tex/<topic>/**` | `latexmk -cd -g tex/<topic>/main.tex` for each touched topic |
| `tex/preamble.tex`, `tex/colophon.tex`, `.latexmkrc` | the same, for all 8 topics |
| `scripts/**` | `python -m unittest discover -s scripts -t scripts -p 'test_*.py'` |

`-g` is not optional: latexmk caches a previous failure and reports "Nothing to
do" for a file that does not compile. A single topic takes about 0.8 s and all
8 about 7 s, so there is never a reason to skip this.

Aux files and `main.pdf` are gitignored. Leave them; do not run `latexmk -c`.

## 6. Plan, and stop

Print the plan and **wait for confirmation**. Nothing before this point has
changed the repository; nothing after it is reversible.

The plan states, in this order:

1. **Routing** — `main`, or a branch named `<type>/<kebab-slug>`, and which
   classification forced it.
2. **The commits** — for each, the literal subject line and the exact paths it
   stages. One commit per (topic, type). Never split hunks within a file.
3. **Anything unexplained** — files from step 4 that the user has not mentioned.
4. **Gate results** — one line, so a green run is visible rather than assumed.

```
2 commits on main:

  feat(manifold): add a definition of tangent spaces
    tex/manifold/ch01.tex
  chore(topology): fix a typo in the separation axioms
    tex/topology/ch02.tex

Gates: manifold OK (0.8s), topology OK (0.8s)

Proceed?
```

If the plan bundles two mathematical units into one commit because they share a
file, say so on that commit's line. The user may want to commit the first
himself and re-run.

## 7. Execute

**Content only** — stage the exact paths, commit, `git push origin main`.

**Shared present** — commit the CONTENT part to `main` first with a path-scoped
`git add`, push it, then `git switch -c <type>/<slug>`, commit the SHARED
remainder, `git push -u origin HEAD`, and `gh pr create`. Report the PR URL and
**stop**; merging is `/git-merge`.

When the two halves are one coherent change and the user said to keep them
together, put both on the branch instead.

Commit messages follow `docs/git-strategy.md`: conventional, English,
imperative, ≤ 72 characters, no trailing period. Scope is the topic directory
for content, the file stem for shared `.tex`, omitted otherwise.

Add `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` — with your own
model name — only to commits Claude authored — `scripts/`, `.github/`, `docs/`, `.claude/`, `tex/preamble.tex`,
`tex/colophon.tex`. **Never on `tex/<topic>/**`**: that mathematics is the repo
owner's and this command only transported it.

### Never

`--force`, `--force-with-lease`, `commit --amend` on a pushed commit, rebasing
a branch with an open PR, `git add -A`, `git add .`. A bad commit on `main` is
corrected by a follow-up commit.

## 8. Report

Print the resulting `git log --oneline -n <count>` and the PR URL if one was
opened.

Then note what CI will do: a push touching `**.tex` triggers `build-pdf.yml`,
which commits `chore(ci): update compiled PDFs` back to `main` a couple of
minutes later; every push triggers `update-readme.yml`. The next `/git` will
rebase over them automatically, so the user does not need to do anything —
say that rather than leaving them to wonder.

Do not poll `gh run list` waiting for the build. Mention that it is running and
finish.
